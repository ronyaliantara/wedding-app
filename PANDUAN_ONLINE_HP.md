# 📱 Panduan Menginstal Mahligai WO di iPhone & Android (Beda Jaringan / Online)

Agar aplikasi dapat dipasang (**Install ke Layar Utama**) di iPhone dan Android dari jaringan mana saja (tanpa harus 1 Wi-Fi yang sama, bisa pakai paket data 4G/5G dari luar kota), aplikasi memerlukan **alamat HTTPS (SSL)** yang valid sesuai standar resmi sistem operasi Apple (iOS) dan Google (Android).

Tersedia **2 Cara Praktis** untuk menggunakannya:

---

## 🌟 CARA 1 (SANGAT DISARANKAN): Hosting Gratis Selamanya di Netlify Drop
> **Kelebihan**: 100% Gratis, Permanen 24 Jam, Laptop **TIDAK PERLU MENYALA**, langsung dapat domain HTTPS resmi sendiri!

### Langkah Mudah (Hanya 1 Menit):
1. Buka browser di laptop dan kunjungi: **[https://app.netlify.com/drop](https://app.netlify.com/drop)**
2. Buka Windows Explorer ke folder proyek ini: `D:\Wedding`
3. **Tarik dan Lepas (Drag & Drop)** seluruh isi folder `Wedding` ke kotak Netlify Drop di browser.
4. Tunggu 10–20 detik sampai selesai.
5. Anda langsung mendapatkan link resmi HTTPS gratis (Contoh: `https://mahligai-wo.netlify.app` atau nama kustom pilihan Anda).
6. **Buka link tersebut di HP Anda:**
   * **iPhone (Apple Safari)**:
     1. Buka link di browser Safari.
     2. Ketuk tombol **Bagikan / Share** (ikon kotak dengan panah ke atas `⎋`) di bawah layar.
     3. Geser dan pilih **"Tambah ke Layar Utama" (Add to Home Screen)** ➕.
     4. Ketuk **Tambah**. Ikon Mahligai WO langsung muncul di layar depan iPhone Anda!
   * **Android (Google Chrome)**:
     1. Buka link di Google Chrome.
     2. Ketuk pop-up **"Pasang aplikasi" (Install app)** yang muncul otomatis di bawah.
     3. Atau ketuk ikon titik tiga (`⋮`) di kanan atas, pilih **"Pasang aplikasi"** atau **"Tambahkan ke Layar Utama"**.

---

## ⚡ CARA 2: Akses Langsung dari Laptop (Tanpa Upload Hosting)
> Cocok jika Anda hanya ingin menghubungkan HP ke laptop secara sementara.

1. Di folder `D:\Wedding`, klik 2x file **`Buka_Akses_Online_HP.bat`**.
2. Tunggu 5-10 detik sampai muncul tautan HTTPS (Contoh: `https://xxxx.lhrun.link`).
3. Buka tautan HTTPS tersebut di browser iPhone (Safari) atau Android (Chrome) menggunakan paket data atau Wi-Fi mana pun.
4. Pasang ke layar utama dengan cara yang sama seperti di atas.
5. *Catatan:* Pada Cara 2, jendela hitam `.bat` dan laptop harus tetap menyala selama Anda mengakses dari HP.

---

## 📦 Cara Memindahkan Data (Laptop ⇄ Smartphone)
Aplikasi menyimpan data dengan aman di browser lokal. Jika Anda sudah membuat data acara di laptop dan ingin datanya langsung ada di HP:

1. **Di Laptop**:
   * Buka aplikasi, klik tombol **"Pengaturan Admin"** (ikon gerigi di kanan atas).
   * Masuk ke seksi **"3. Keamanan & Data"**.
   * Klik tombol **"💾 Cadangkan Data (.json)"**. File backup akan otomatis terunduh.
2. **Kirim File**:
   * Kirim file `.json` tersebut ke WhatsApp Anda sendiri, lalu simpan / unduh di HP.
3. **Di HP**:
   * Buka aplikasi Mahligai WO di HP.
   * Masuk ke **Pengaturan Admin** > klik **"📥 Pulihkan Data (.json)"**.
   * Pilih file cadangan tadi.
   * **Selesai!** Seluruh daftar acara, nama pasangan, lokasi, master kru, dan checklist langsung muncul di HP Anda.
