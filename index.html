📜 4. STATUS LISENSI RESMI APLIKASI

Pasang Mahligai WO di HP

Aplikasi offline tanpa kuota di iPhone & Android

🌐 Bisa Diakses dari Mana Saja (Beda Jaringan / Paket Data):

Aplikasi ini sudah berstandar PWA resmi. Anda dapat meng-hosting folder ini secara gratis & permanen di Netlify Drop, Vercel, atau GitHub Pages, atau gunakan file Buka_Akses_Online_HP.bat di laptop untuk mendapatkan tautan HTTPS langsung!

📱 Untuk Pengguna iPhone (Apple Safari):
  1. Buka link aplikasi di browser Safari (bukan Chrome di iOS).
  2. Ketuk tombol Bagikan / Share (ikon kotak dengan panah ke atas ⎋) di bagian bawah layar.
  3. Geser menu ke bawah dan pilih "Tambah ke Layar Utama" (Add to Home Screen) ➕.
  4. Ketuk "Tambah" di sudut kanan atas. Ikon aplikasi langsung muncul di layar depan iPhone Anda!
🤖 Untuk Pengguna Android (Google Chrome):
  1. Buka link aplikasi di browser Google Chrome.
  2. Ketuk pop-up "Pasang aplikasi" (Install app) yang otomatis muncul di bawah.
  3. Atau ketuk ikon titik tiga (⋮) di sudut kanan atas Chrome, lalu pilih "Pasang aplikasi" atau "Tambahkan ke Layar Utama".
💡 100% Offline Tanpa Kuota: Setelah terpasang, aplikasi tetap dapat dibuka dan digunakan dengan lancar di HP meski tidak ada sinyal internet.
